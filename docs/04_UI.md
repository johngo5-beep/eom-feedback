# UI

## Surfaces

One page only: the public feedback form.

## Principles

- One clear composition: title, short help text, form
- Fast and calm — no dashboard chrome
- Mobile-friendly
- Success state keeps the submitted values visible but read-only

## States

| State | Behavior |
| --- | --- |
| Empty | Editable fields + **Submit** |
| Validation error | Flash messages; fields stay editable with entered values |
| Success | Read-only fields + thank-you + **Write one more feedback** |

## Visual direction

- Font: DM Sans
- Soft gray page background, white form panel
- Green accent for primary actions and success

## Accessibility

- Labels on every field
- Required fields marked
- Focus styles on inputs and buttons
- Success message uses `role="status"`
